접근 허용 IP / CIDR

웹 UI에 접속할 수 있는 IP 목록
한 줄에 하나씩 IP 주소 또는 CIDR 표기를 입력하세요.
예: 192.168.1.0/24, 10.0.0.5
목록이 비어 있으면 모든 IP에서 접근 가능합니다.
현재 내 IP를 허용 목록에 포함하지 않으면 설정 저장 후 접근이 차단될 수 있습니다. 현재 접속 IP를 반드시 포함해주세요.

API 키 안내

에이전트와 Hub 간 통신에 사용되는 API 키는 hub/config.yaml의 security.api_key에서 변경합니다.
에이전트의 agent/config.yaml의 hub.api_key와 동일한 값으로 설정해야 합니다.

강력한 API 키 생성 명령어: python -c "import secrets; print(secrets.token_hex(32))"
